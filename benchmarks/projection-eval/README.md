# Projection Eval Fixtures

This directory holds the minimal deterministic projection-eval adapter fixtures.

- `benchmark/run.mjs projection-eval --suite <json>` runs shell commands for the same case input, captures their stdout JSON manifests, and scores them with `evaluator.mjs`.
- The evaluator only compares machine-readable manifests plus hard assertions from the suite.
- There is no model judge in this flow.
- For real model evaluation, rerun the baseline/candidate models separately and capture fresh manifests; this fixture path is only the adapter and scoring harness.

Fixture layout:

- `fixtures/suite.json`: example suite for tests
- `fixtures/mock-runner.mjs`: pure Node command used by tests
- `fixtures/inputs/*.json`: per-case inputs consumed by the mock runner
- `corpus/cases.json`: frozen Phase 0 durable-fact scenario matrix
- `corpus/rubric.json`: hard assertions, thresholds, and diagnostic-only metrics
- `baseline/legacy-phase-0-scorecard.json`: frozen legacy projector observation matrix

The Rust legacy projector exports the shared manifest through
`EffectivePrompt::projection_manifest()`. The committed baseline freezes the
corpus and budget matrix; per-activation manifest artifacts are generated by
the debug/fixture command used by a suite.
