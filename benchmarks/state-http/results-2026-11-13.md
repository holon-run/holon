# State response-byte retention experiment — 2026-11-13

## Scope and provenance

A retains completed State response bytes. B removes only that retention, keeping
admission, in-flight sharing, cancellation and invalidation. Both use the same
offline [State HTTP fixture](../state-http.md), not the running daemon or a real provider.

- Base: `8fa168725d53ca140b7395f16df147bed905b7a3`, plus this change.
- Toolchain: Rust 1.100.0, macOS ARM64, release profile,
  `RUSTFLAGS="-D warnings"`, `CARGO_PROFILE_RELEASE_DEBUG=0`.
- Fixture SHA-256: `bd8cf55f735c00eb3f39ceb8793404299aa6d41bd6c3db73b433494fa38501a2`.
- A executable SHA-256: `84789f02709357445150b81cbfe0757c3f4d7e5290b809645909d610db3c6e37`.
- B executable SHA-256: `54d830c7be1f5f16a4c91634676c5ec474136f8bb5a9030dbed5fa1fed214969`.

The build manifest records full source fingerprints. Source was restored to B
after building A; both source and executable hashes were checked before AA.
Later Python diagnostic-driver changes did not rebuild the frozen executables
or change the Rust fixture.

AA used 300 requests × 3 batches per process. ABBA used 200 requests × 3 batches,
10ms pause per client, four runtime worker threads, and one shared gate. Processes
ran sequentially without a concurrent build/benchmark; other host activity was
not isolated. AA p50 batch medians were 0.079/0.043ms, p95 0.125/0.100ms and CPU
125/106µs per request. Each process had 879 cache hits in 900 requests and identical
26,390-byte response medians. This variation limits precision for small differences.

## Concurrent mutations: not a passing latency matrix

The original full invocation stopped in the first mutation A process, third batch,
on typed `agent_reconciliation_pending` HTTP 503. Its first two batches each
completed 200 requests and 39 Work commits. The failure remains preserved.

A separate `--matrix mutations --keep-going` ABBA diagnostic used the same frozen
executables/settings. Each process still stops new requests on its first non-200;
already-running workers may also fail. Other independent processes continue,
without request/cell retries. Failed runs have no successful summaries; the driver
exits 1. All failed diagnostic processes emitted `agent_reconciliation_pending`.

| Agents | Clients | A complete processes | B complete processes | A 200/503 | B 200/503 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 1 | 1/2 | 0/2 | 1029/1 | 28/2 |
| 1 | 10 | 2/2 | 0/2 | 1200/0 | 180/17 |
| 8 | 1 | 0/2 | 0/2 | 717/2 | 68/2 |
| 8 | 10 | 2/2 | 0/2 | 1200/0 | 288/2 |

These are censored unequal-length observations, not steady-state error-rate
estimates. No comparable successful mutation latency/CPU result is claimed;
successful A processes are not selected as replacements for failed runs. B exposes
unavailable commit windows that A can sometimes hide behind completed bytes; A
can still encounter them on misses. A deterministic HTTP regression separately
checks the B contract: 200 → open commit reservation → typed 503 → close → 200.

## Interpretation and evidence limitations

Removing completed-byte retention eliminates that TTL freshness window, not
publication lag or client polling delay. It costs CPU/allocations and exposes more
transient unavailability. Loaded B p50 was about 0.5–5.1ms; cold B p50 about
3.2–30.9ms, with corresponding CPU costs in the table. This describes a freshness/
availability/resource tradeoff, not a performance win or universal acceptable
budget. The 28-scenario matrix was attempted but did **not** pass in full.

In-process `Router::oneshot` includes full body collection but excludes socket/
transfer cost. Attribution stages are inclusive/overlapping, not exclusive CPU.
These results do not prove Host-wide atomicity or provider-load behavior and do
not resolve unrelated writer contention.

Raw build/AA/partial-full/diagnostic manifests, JSON and stderr remain in the local
`state-cache-20261113/final-v5` evidence bundle alongside older failed attempts.
They are not committed or published by this report; this summary is not a link to
public raw artifacts. Reproduce using the fixture guide.
