# 会话布局与右侧面板改进计划

- 日期：2026-09-16
- 状态：已实施（2026-09-16）；P0–P2 已完成，验证范围见文末。
- 范围：Web GUI 三栏布局、右侧概览与对象详情、文件浏览与最大化阅读。
- 依据：[现有设计约定](../DESIGN.md)、[会话读模型 RFC](../../docs/rfcs/conversation-read-model.md)，以及本地 holon-dev / holon-test 页面观察。

## 1. 目标与必须保留的能力

让中间会话保持稳定、可读；右侧既能快速检查执行详情，也能展开为适合阅读文件、代码、diff 和媒体的完整工作区。

必须保留：

- 历史按 turn 展示 brief，当前 turn 动态展开过程，结果可读后自动收缩。
- 工具行的参数摘要，以及点击后进入现有专用详情渲染器的行为。
- 右侧文件浏览器及其工作区入口、目录导航、文件链接跳转、搜索/筛选、排序、预览、下载等现有能力。
- 右栏拖动调整宽度、最大化、还原和关闭；最大化不是删除或替换文件浏览器的理由。
- 当前工作区和 execution root 的身份边界，以及现有 API、错误和截断提示。

本轮不改 runtime/SDK 协议，不引入第二套会话数据源，不扩展为文件编辑器、终端或完整 IDE。

## 2. 当前观察

### 布局

当前常规三栏使用 `240px 导航 + 弹性会话 + 420px 右栏`：

| 窗口宽度 | 左栏 | 中栏布局宽度 | 右栏 | 行为 |
| --- | --- | --- | --- | --- |
| 1600px | 240px | 940px | 420px | 三栏并排 |
| 1440px | 240px | 780px | 420px | 三栏并排 |
| 1280px | 240px | 1040px | 420px | 右栏覆盖中栏 |
| 1024px | 240px | 784px | 420px | 右栏覆盖中栏 |

1340px 以下切换覆盖层时，正文和输入框仍按未扣除右栏的宽度排版，造成文字和按钮被遮挡。右栏拖动上限当前按窗口宽度的 70% 计算，未直接保护中栏最小宽度。

### 右栏

- Agent 名称、生命周期、模型、当前工作、调度说明和管理按钮占据大块首屏空间。
- 卡片边框、阴影、大小标题叠加；工具详情中存在通用标题与具体工具名重复。
- 文件浏览器是现有 `file_browser` 视图；最大化通过 `normal / expanded` 模式实现。
- 当前最大化会收起左侧导航，覆盖除 72px 图标栏外的工作区；已有还原按钮、分隔线双击、Cmd/Ctrl+. 和 Escape 行为。
- 文件目录、选中文件及阅读状态主要在组件内部。切换视图导致卸载时，需要明确哪些状态应恢复。

## 3. 目标布局

### 3.1 分开管理内容和显示模式

右侧“看什么”和“占多大空间”互不替代：

- 内容：概览、文件浏览、选中的工具/任务/WorkItem 等详情。
- 显示模式：关闭、并排、最大化。
- 响应式布局：空间不足时采用完整详情视图，这是布局适配，不覆盖用户保存的并排宽度或最大化偏好。

内容切换不自动关闭或还原最大化；新执行事件不抢走正在阅读的文件。只有用户显式点击某个执行项或文件链接时才切换对象。

### 3.2 并排模式

```text
┌──────────────┬───────────────────────────┬─────────────────────┐
│ 导航 / Agent │ 会话标题                  │ 概览  文件  详情  ⤢ ×│
│              │                           │ 当前对象标题 / 路径  │
│              │ turn / brief / 执行过程   │                     │
│              │                           │ 对象内容             │
│              │ 输入框                    │                     │
└──────────────┴───────────────────────────┴─────────────────────┘
```

建议初始尺寸（实施时结合中英文和长路径复核）：

- 左栏展开宽度约 224px；收起继续使用现有 72px，避免另造一套导航尺寸。
- 右栏默认约 380px，最小约 320px；已有合法用户宽度优先保留。
- 中栏并排时至少 640px，正文及输入框最大宽度统一在 720–760px。
- 右栏最大宽度由剩余空间决定：窗口宽度减左栏、分隔线及中栏最小宽度。超过该宽度的阅读需求通过最大化满足。
- 依据剩余空间计算布局，不再仅用固定 1340px 断点切换遮挡式浮层。

空间不足时先临时收起左栏；仍不足以容纳中栏与右栏时，右侧切换完整详情视图，显示“返回会话”。不展示一条被遮住、仍可误触的会话残片。

临时收起与用户主动收起必须区分；关闭详情或空间恢复后，仅恢复系统临时改变的导航状态。窗口变化时重新约束实际栏宽，不把临时约束结果写回用户偏好。

### 3.3 最大化模式：文件阅读的一等能力

桌面最大化时，右侧占满除左侧 72px 导航外的可用工作区，不为中间会话保留空列；窄屏使用整个视口。

```text
┌─────┬───────────────────────────────────────────────────────┐
│导航 │ ← 返回来源     概览  文件  详情              还原  关闭 │
│图标 ├───────────────────────────────────────────────────────┤
│     │ holon / docs / example.md                            │
│     ├──────────────┬────────────────────────────────────────┤
│     │ 目录导航     │ Markdown / 代码 / 图片 / PDF 等预览     │
│     │（可折叠）    │                                        │
│     │              │                                        │
└─────┴──────────────┴────────────────────────────────────────┘
```

- 保留常驻、可聚焦的最大化/还原按钮，图标有明确名称和提示。
- 保留 Cmd/Ctrl+. 切换、分隔线双击切换；Escape 先退出最大化，再关闭普通面板。弹窗、输入法等优先处理自己的 Escape。
- “返回来源”回到之前的对象；“还原”只改变布局；“关闭”返回会话。三个操作的语义保持清楚。
- 最大化不会清空会话、重新拉取历史或取消活动 turn；会话可在后台继续接收更新。
- 还原恢复先前的并排宽度、左侧导航状态、当前文件、阅读位置，以及会话滚动锚点。
- 如果当前窗口已经不能并排，还原后进入响应式完整详情视图；提供“返回会话”，不强行挤出三栏。
- 完整详情视图和最大化下，被覆盖的会话内容退出键盘焦点顺序；离开后将焦点恢复到触发入口。

## 4. 文件浏览器的具体处理

### 入口与导航

- 右栏提供稳定的“文件”入口，不必每次先展开 Agent 概览、工作区卡片。
- 保留从工作区、brief 文件链接、工具产物及 WorkItem 计划文件打开的路径。
- 顶部展示工作区与文件路径面包屑；长路径允许省略，完整路径可查看/复制。
- 工具详情 → 文件 → 返回来源时，恢复原工具详情的位置和选择状态。

### 窄栏与最大化预览

- 普通窄栏沿用目录列表与文件预览之间的切换，避免再切成两条难读的小列。
- 最大化后，当文件区自身宽度足够（初始参考 960px）时，可提供约 220–260px 的可折叠目录导航与弹性预览区。
- 目录导航复用现有目录 API 和列表，不递归扫描整个工作区；文件直达时同步显示其所在目录。
- Markdown 正文保持阅读宽度，表格和代码块可独立横向滚动；源码、diff、图片和 PDF 使用可用宽度。
- 文件区采用独立滚动：固定工具栏，目录与预览各自滚动，避免面板、文件、页面三层嵌套滚动。
- 保留现有 Markdown/源码切换、图片、音视频、PDF、二进制提示和下载功能。大文件截断、失败、加载中必须继续可见。

### 状态保留

- 在“概览 / 文件 / 详情”之间切换，以及最大化/还原时，保留目录、选中文件、筛选条件、排序、预览模式和阅读位置。
- 目录与预览的滚动位置分别保存；文件打开链支持返回之前的来源。
- 状态按 remote、agent、workspace、execution root 区分，防止不同上下文的同名文件混用。
- 仅保留必要的 UI 状态和有界缓存；不为保持位置而长期挂载所有历史文件或媒体。
- 不因每个会话事件刷新文件内容；显式刷新和现有失效机制继续负责内容更新。

## 5. 右侧信息层级及整体密度

### 右侧概览

顺序调整为：

1. Agent 名称与当前状态，一行呈现。
2. 当前工作、进度、需要用户处理的事项。
3. 工作区名称及文件入口，完整路径按需展开。
4. Skills、模型、运行信息等折叠分组。

无当前工作时只显示一行提示，不再用大块空状态卡片重复说明。管理操作收进菜单；当前运行的停止按钮继续保留在输入区。部分卡片边框与阴影改为细分隔线。

### 当前详情

标题直接使用工具名、文件名或工作项标题，简化重复的“Context side panel / Tool execution”等通用标题。保留状态、必要的路径及返回来源。

执行行选中时轻量高亮，方便对照；概览、文件和详情各自保留浏览位置。文件和工具详情沿用现有专用渲染器。

### 左栏与输入框

- 降低头像和常态状态图标的视觉强度，突出选中、执行中、未读与待处理状态。
- 名称作为主行，ID 按需展示；为 Agent 列表提供快速筛选。
- 空输入框目标高度约 96–112px，输入多行后增长，保留附件、模型、思考级别和发送/停止入口。
- 正文与输入框共享阅读轴线；右侧打开、关闭、还原时维持会话滚动锚点。

## 8. 验收标准

### 布局矩阵

在 1600、1440、1280、1024、768、390px 宽度下，检查导航展开/收起、右栏关闭/普通/最大化，以及拖动后缩放窗口：

- [x] 正文和输入框不被普通右栏部分遮挡；窄屏完整详情视图有明确返回入口。
- [x] 页面无意外横向溢出；源码和大表格只在自己的区域横向滚动。
- [x] 最大化真正使用可用工作区；还原不丢失合法用户栏宽或导航偏好。
- [x] 中英文、长文件名、长命令和大表格均可用。

### 文件与详情往返

- [x] 从 brief、工作区、工具产物、WorkItem 计划入口打开文件，定位到正确的 workspace/execution root。
- [x] 阅读并滚动文件 → 最大化 → 切换概览/工具详情 → 回到文件 → 还原，选中文件、模式和位置保留。
- [x] 从工具详情打开文件后返回，恢复原工具及其位置。
- [x] 新执行事件到来时，文件预览不被抢占；返回会话后能看到正确进度和最终 brief。
- [x] Markdown、源码、图片、音视频、PDF、二进制及截断/错误提示无回归。
- [x] Escape、Cmd/Ctrl+.、分隔线双击、键盘焦点与 reduced-motion 行为明确。

### 验证与交付

- 为布局状态恢复、文件往返及会话不中断增加有意义的浏览器回归测试；复用现有文件预览和工具渲染测试。
- 运行相关单元测试、类型检查和浏览器测试，再执行 `make web`；不要与安装依赖的构建步骤并发运行测试。
- 刷新本地 holon-dev / holon-test 页面，以真实 Markdown/源码文件和工具结果复核并排、最大化和还原。
- 分阶段提交；实施完成后更新 `web-gui/DESIGN.md`，把最终交互写成现行约定，并标记本计划完成。


## 9. 实施结果与验证记录（2026-09-16）

- 完成自适应三栏：224px 导航、72px 紧凑导航、380px 默认右栏、320px 最小右栏和 640px 最小并排会话区。窄屏完整详情视图不再部分遮挡正文与输入框。
- 保留最大化/还原、关闭、分隔线双击和快捷键，并增加键盘调整栏宽。临时窗口限制不覆盖保存的宽度；覆盖的会话不进入焦点顺序、不把后台新结果标成已读。
- 右栏增加概览/文件/详情入口、工作区选择、当前对象标题与返回来源；简化概览、折叠运行设置和管理操作、增加 Agent 筛选、压紧输入框。
- 文件区宽度达到 960px 时可显示 240px 目录列与预览；保留原有目录/预览切换、内容渲染、文件链接、下载与错误提示。
- 文件浏览状态保留在右栏的有界内存快照中：最多 6 个浏览位置、每个位置最多 4 个此前文件选择；不常驻所有文件组件。关闭/切换视图卸载媒体预览。remote/runtime/auth scope、agent、workspace、execution root 隔离状态。
- 从 Markdown 链接打开文件会同步目录上下文，并支持返回之前文件；增加请求代次检查，防止迟到的读取覆盖较新的选择。
- 设计约定已同步到 `web-gui/DESIGN.md`。

验证：

- 类型检查通过，47 个测试文件共 541 个单元测试通过。
- 完整浏览器回归：19 个测试通过（含运行时身份迟到的新增回归）。覆盖 1600/1440/1280/1024/768/390px 布局、栏宽保存与还原、文件/概览切换、Markdown 链接返回、源码模式及滚动恢复、最大化期间实时 turn/brief 更新、返回原工具详情，以及原有会话折叠、滚动、停止执行和连接恢复。
- 真实 localhost:7878 页面使用仓库 README 验证了目录导航、最大化并排预览及还原到 1280px 的三栏阅读；最终 `make web` 通过，重新检查最终构建的真实文件最大化与还原成功。
- 媒体格式、下载、截断和错误路径复用原渲染器及现有测试；本次没有逐一人工播放全部音视频/PDF 格式。上方验收勾选表示实现已保留这些能力，不表示所有格式都做过人工实测。

- 最终真实页面复核额外发现并修复了初始化时序问题：首次补齐 discovery identity 不重挂载文件浏览器；已有 identity 真正变更时仍清空作用域缓存。新增延迟 roster 响应的浏览器测试验证该行为。
