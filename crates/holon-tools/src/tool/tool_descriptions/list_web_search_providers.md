List the provider IDs you can pass unchanged to `WebSearch(provider="<ID>")`. Takes no arguments. Returns `{"providers":[{"provider_id":"<ID>","source":"configured|builtin|derived"}]}` with sorted, unique IDs, or an empty array when WebSearch is disabled or no provider qualifies. `source` marks where each entry comes from: `configured` (explicit `web.providers` entry), `builtin` (built-in keyless route), or `derived` (auto-derived from an authenticated model provider with standalone-dispatchable native search). Uses local configuration only; it does not search, send requests, start commands, or check provider health. Routing selectors and conversation-only native search are not listed as provider IDs.
