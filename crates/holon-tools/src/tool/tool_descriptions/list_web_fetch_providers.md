List the WebFetch routes you can use right now: the default local HTTP route (`provider_id: null`) plus each callable remote provider ID with its `kind` and supported `extract_modes`. Pass a listed remote `provider_id` unchanged to `WebFetch(provider="<ID>")`; only remote IDs are accepted there, and the local route is selected by omitting `provider` (an empty string is a registry lookup, not the local route). Takes no arguments. Returns `{"providers":[...]}` with the local route first and remote IDs sorted, or an empty array when web fetch is disabled.
