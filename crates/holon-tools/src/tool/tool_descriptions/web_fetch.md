Fetch a specific http or https URL through Holon's web policy, extract readable text, wrap it as untrusted external content, and return provenance including final URL, status, status source, provider ID, content type, truncation, and hash. Omit provider for local HTTP fetching (provider_id=null, status_source=target_http). Set provider to a configured remote fetch provider ID discovered via `ListWebFetchProviders` to explicitly use its extraction API. Currently only kind=deepseek is callable remotely (auto mode only, Markdown output). Remote fetching discloses the URL to the provider, returns final_url=null with source=deepseek_remote and status_source=provider_api; status is the provider API status, not the page's HTTP status. It cannot enforce custom host rules or redirect limits; use local fetching when those are configured. Path and query in the URL are sent to the chosen service; do not pass signed, token-bearing, or non-public URLs.
