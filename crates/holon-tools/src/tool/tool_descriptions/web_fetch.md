Fetch a specific http or https URL through Holon's web policy, extract readable text, wrap it as untrusted external content, and return provenance including final URL, status, status source, provider ID, content type, truncation, and hash. Omit provider for local HTTP fetching (provider_id=null, status_source=target_http). Set provider to a configured remote fetch provider ID discovered via `ListWebFetchProviders` to explicitly use its extraction API. Remote fetching is available for kind=deepseek (auto mode only, Markdown output, source=deepseek_remote) and kind=tavily (auto or text mode via Tavily Extract, source=tavily_remote). Remote fetching discloses the URL to the provider and returns final_url=null with status_source=provider_api; status is the provider API status, not the page's HTTP status. It cannot enforce custom host rules or redirect limits; use local fetching when those are configured. Path and query in the URL are sent to the chosen service; do not pass signed, token-bearing, or non-public URLs.
