Pause on an explicit wake condition or consume an already-available task result. Set `wake` (`task_result` with `resource=<task_id>`, `timer` with `resource=<timer_id>` from `CreateTimer`/`ListTimers`, `system`, `external` with optional external locator, or `operator_input`), a concrete `reason`, `delivery` (`final` when yielding requires a non-empty operator brief; `silent` otherwise), and optional `recheck_after_ms`.

Waiter ownership resolves from the execution-bound WorkItem first (ignoring a conflicting explicit `work_item_id` with receipt disclosure), then an explicit owned open `work_item_id`, turn-bound WorkItem, current focus, or agent lifecycle; any WorkItem of this agent may hold a `task_result` wait without migrating task ownership. Follow `result.continuation` (`continue_turn`, `yield_and_wait`, or `yield_and_reenter`), and if `awaiting_final_report` is returned, follow the deferred receipt's continuation instructions. Cancelling a timer terminates dependent unadmitted waits (`timer_cancelled`) without resuming execution.
