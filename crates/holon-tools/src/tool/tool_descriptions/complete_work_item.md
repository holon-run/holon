Mark the turn-owned open WorkItem completed by `work_item_id` once its objective and verification are satisfied (do not call just to move from planning to implementation—use `UpdateWorkItem` with `plan_status=ready` instead). Establish any runnable successor WorkItem before completing so remaining work is not orphaned.

Completion settles the current execution, may resume a yielded caller, and ends the turn (detached completion while an execution attempt is open is rejected). Provide a non-empty operator-facing completion report as assistant text in the same round to promote as the canonical result, or follow the deferred receipt's continuation instructions if `awaiting_completion_report` is returned.
