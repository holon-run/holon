Request safe durable deletion of a retained ephemeral child you currently supervise, supplying current `agent_id` and `incarnation` from `GetAgent` or `ListSubagents` once the child is no longer needed (public, independent, peer, or recreated agents are excluded).

Accepted calls return an idempotent deletion job (cancelling admitted timers and ignoring runtime `tool-artifacts/`, `task-output/`, and `work-items/`). Active execution, live waits/settlements, descendants, unsafe worktrees, or nonempty user deliverables (`work/`, `notes/`, `media/`, `apps/`) block safe deletion—resolve blockers honestly rather than stopping valid live work just to force cleanup.
