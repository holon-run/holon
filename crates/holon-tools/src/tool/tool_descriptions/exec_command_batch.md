Run a sequential batch of short, non-interactive shell commands (`items` with `cmd` and optional `workdir`, `shell`, `login`, `yield_time_ms` defaulting to `30_000` ms, `max_output_tokens`, plus optional top-level defaults and `stop_on_error`) and return one grouped receipt. Timed-out items are not promoted to `command_task`; use `ExecCommand` for long, uncertain, or interactive runs.
