Search Holon memory sources: runtime evidence (messages, briefs, work items, tasks, tool receipts) plus the curated agent memory markdown files agent_memory:self and agent_memory:operator. Other markdown files (notes, workspace docs, source code) are NOT indexed. Each result includes an opaque source_ref that can be copied verbatim to MemoryGet. index_status.stale_reasons explains any temporary staleness; the background indexer self-heals it, so retries are usually better than switching tools.

Optional `agent_ids` narrows the search to an explicit agent scope: omitted, empty, or blank-only values keep the default caller-only search; a non-empty list searches only the listed agents (whitespace-trimmed, deduplicated; unknown ids match nothing and never implicitly add the caller). Hits owned by another agent are evidence only: `metadata.cross_agent` records `origin_agent_id`, `evidence_only`, and the source `source_authority_class` from trusted indexing metadata, and that authority never transfers to the current agent. Verify originals through MemoryGet. `index_status` reports the aggregate; with multiple agents `index_status_by_agent` reports each agent's status.
