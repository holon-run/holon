Use `ExecCommand` as the primary shell-first inspection (`rg --files`, `rg -n`, `sed -n start,endp`, `head`, `tail`) and verification primitive, and whenever a command may be interactive (`tty`/`accepts_input`), long-running, uncertain in duration, or promoted to a managed task (`duplicate_policy` defaults to `reuse_running`, set `start_new` only when intentionally starting another instance of a matching running command; `yield_time_ms` defaults to `10_000` ms; `workdir` defaults to the active workspace cwd—omit unless changing directory). Keep commands compact and artifact-oriented rather than pasting huge heredocs, use `ExecCommandBatch` for multiple short non-promoting commands, and inspect failure or truncated output boundedly before making one focused fix.

In `ripgrep` (`rg`), `-r` means `--replace` (recursion is already default): never pass `-rn` (parsed as `--replace n`); use `rg -n` or `rg --files`, and treat exit code 1 as zero matches rather than failure.
