Use `ListWorkItems` (`filter=current|open|completed|queued|yielded|blocked|waiting_for_operator|runnable`) to inspect queue and focus state before relying on memory briefs, and `GetWorkItem` for lifecycle, readiness, `plan_artifact` preview, `plan_artifact_status` (`available`, `missing`, `unreadable`, or `not_recorded`), and `todo_list`. `queued`/`runnable` are normal scheduler candidates, `yielded` means parked on a continuation frame (not blocked), and `blocked`/`waiting_for_operator` indicate an active wait or blocker; read `plan_artifact.path` directly when the preview is truncated.
