Use `ListTasks` (`limit` default 20, max 100) for active non-terminal task digests and `TaskStatus` for exact lifecycle or historical state (`TaskStatus` is not an output reader: check its command runtime paths/availability before bounded `ExecCommand` reads, and use bounded read-only `holon tail --agent <agent_id> --include-progress` rather than `GetAgent` for live agent progress). When ordinary completion is all that remains, call `WaitFor(wake=task_result, resource=<task_id>)` instead of polling. Use `TaskInput` only on live tasks that support follow-up (`accepts_input` for commands, `child_supervision.followup_target` for child tasks—never to restart terminal handles), and `TaskStop` only when a task is obsolete or blocking.
