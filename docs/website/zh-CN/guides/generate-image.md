# 生成图片

Agent 可以通过 `GenerateImage` 工具生成图片。你只需要描述想要的内容，Agent 就会调用工具并将结果保存到本地。

## 开始之前

- Agent 具有调用 `GenerateImage` 的权限。
- 已配置图片生成路由及服务商凭据。请参阅[配置模型](configure-models.md)；普通的会话模型可能不支持生图能力。
- 运行时可以正常连接模型服务商，并具备向 Agent 的媒体目录写入文件的权限。

## 操作步骤

1. 告诉 Agent 你需要什么样的图片：

   ```text
   帮我生成一张温馨阅读角的插画，带有一盏复古桌灯，浅色木质背景，保存为 desk-lamp.png。
   ```

   Agent 会根据你的提示词与支持的输出格式调用 `GenerateImage`。每次调用只生成单张图片；如需多张不同图片，请分别发起请求。

2. 让 Agent 汇报返回的文件引用。生成的图片保存在 `agent_home/media/generated` 目录下；用户指定的名称不能替代实际保存的文件路径。

3. 从回复中的文件链接或客户端文件浏览器中打开图片。如果需要让 Agent 自行核对图片内容，请参阅[检查图片](inspect-image.md)。

## 确认结果

核对工具是否执行成功并返回了图片引用与元数据，然后打开保存的图片文件。对照你的提示词检查图片细节；服务商调用成功并不保证请求的每一个细节都已完美呈现。

## 故障排查

- **未配置生图模型：** 请按照[配置模型](configure-models.md)检查生图路由与服务商凭据。
- **参数不受支持：** 请使用当前模型支持的尺寸、格式与背景模式。具体可用取值可查阅参考文档。
- **服务商或网络错误：** 重试前请先阅读返回的具体错误信息。未获得工具成功返回前，不要把图片当作已成功生成。
- **无法打开图片文件：** 请检查运行时主机上的返回路径。远程主机的本地文件系统路径并不等同于你本地笔记本电脑的路径；请使用客户端的产物查看器或下载功能。

## 尺寸与格式

关于支持的尺寸、背景模式、输出格式以及兼容模型列表，请参阅[图片生成参考](../reference/image-generation.md)。
