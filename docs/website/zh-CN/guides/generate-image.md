# 生成图像

Agent 可以用 `GenerateImage` 工具根据文本提示词生成图片。你描述想要的画面，
Agent 调用工具并把结果保存下来。

## 前置条件

- 已经配置好图像生成。没有配置时，工具会报告没有可用模型。见
  [图像生成参考](/zh-CN/reference/image-generation.md)。

## 步骤

1. 把你在意的细节说清楚：

   ```
   生成一张 1024x1024 的成品图：白色背景上一盏哑光黑色台灯。
   保存为 desk-lamp.png。
   ```

   Agent 会把它转成一次 `GenerateImage` 调用，包含提示词、尺寸
   （`1024x1024`、`1536x1024` 或 `1024x1536`）、背景和输出格式。

2. 让 Agent 告诉你文件放在哪里。生成的图片写在 Agent 的媒体目录下。

## 确认成功

结果里会说明保存的文件、格式和尺寸。如果工具报错，信息会指出是模型的问题还是
尺寸的问题。

## 尺寸与格式

尺寸、背景、格式选项和支持的模型见[图像生成参考](/zh-CN/reference/image-generation.md)。
