# 使用 iOS 客户端连接

将 iPhone 或 iPad 连接到 Holon 运行时，发送指令并直接查看生成的产物与文件。离线状态下依然可以浏览之前缓存的对话记录，但这并不代表与运行时的连接处于畅通状态。

## 前置条件

- 已启动并启用 HTTP 访问的 Holon 守护进程（默认端口 `7878`）。
- 运行 iOS 18.0 或更高版本的 iPhone/iPad，或兼容的 Xcode 模拟器。
- 到守护进程的网络通路（局域网、反向代理或 tailnet）。
- 配对邀请码、控制 Token 或组织单点登录入口。

## 安装客户端

### 安装官方分发包

若你收到了 TestFlight 邀请，请在设备上打开兑换链接进行安装。其他分发渠道请关注官方发布通告；本指南不代表 App Store 已上架正式包。

### 从源码构建

Xcode 本地构建与运行步骤已归档至[构建移动端客户端](../maintainers/build-mobile-clients.md#ios)。

## 连接到守护进程

### 方案 A：二维码扫码配对（推荐）

1. 在电脑浏览器打开 Holon Web GUI，进入 **Settings** -> **Device Pairing**（或在 macOS 状态栏菜单中点击 **Pair Device**）。
2. 在 iOS 设备上打开 Holon 应用。
3. 在欢迎页点击 **Scan connection QR code**。
4. 用手机摄像头扫描 Web GUI 或终端中展示的配对二维码。

应用会读取邀请票据（`/login#pair=<ticket>`），请求 `POST /api/auth/pairing/redeem/native` 完成兑换，将会话凭据安全加密存入 iOS Keychain 中，随后直接进入 Agent 列表。

如果摄像头不可用或权限受限，可将配对链接直接粘贴到欢迎页的地址输入框，点击**下一步**后确认连接。

### 方案 B：手动连接

1. 在欢迎页的地址输入框输入完整的 API 基准 URL（例如 `https://holon.example.com/api` 或 `http://192.168.1.50:7878/api`），也可直接粘贴。
2. 点击 **下一步**，应用会自动探测该主机的登录方式。
3. Token 主机会显示访问令牌输入框，输入 Bearer Token 或 Bootstrap Secret 后点击 **使用 token 登录**。
4. 登录后阅读数据共享声明（其中明确列出了主机配置的 AI 数据接收方）并点击 **继续**，之后才会进入 Agent 数据。

应用调用 `POST /api/auth/session/exchange/native`，将颁发的可吊销会话凭据存入 Keychain，并立即清空内存中的明文 Token。

### 方案 C：组织单点登录（OIDC）

当守护进程对接了 OpenID Connect 身份提供商时：

1. 在地址输入框输入 API 基准 URL 并点击 **下一步**。
2. 应用探测到组织登录后会自动弹出系统浏览器面板；如需重试可点击 **组织浏览器登录**。
3. 在系统浏览器面板中完成身份认证。
4. 认证完成后通过自定义 URL 回调重定向回 Holon，应用将下发的会话 Token 妥善存入 Keychain。

## 网络与安全考量

- **优先使用 HTTPS：** 生产环境强烈建议配置 HTTPS。跨网络通过明文 HTTP 连接会在配对或登录前触发系统显式安全警告。
- **本地网络权限：** 在家庭或办公 Wi-Fi 局域网中直连时，必须在系统弹出请求时授予 iOS “本地网络”权限。
- **回环地址限制：** 在实体 iPhone 上，`127.0.0.1` 和 `localhost` 指向手机自身。请使用电脑主机的局域网 IP 或 Tailscale MagicDNS 域名。

## 日常导航与移动体验

成功连接后，选择一个 Agent 并发送一条安全的测试消息：

```text
请回复“iOS connection verified”，不要修改任何文件。
```

等待接收新的完成摘要（Brief）。确认请求已成功发送至选定的运行时，而非滞留在本地发送队列。

- **可搜索的 Agent 名册：** 首页展示所有具备访问权限的 Agent，带有实时状态与最新动态摘要。支持按最近活跃度、等待回复状态或名称快速筛选。
- **结果优先的时间线：** 对话流以用户请求与 Markdown 最终交付摘要为核心。底层详细的执行轨迹与工具调用会自动收拢进可展开的轮次条目中，阅读产物时不会被冗长的日志淹没。
- **后台任务状态一览：** 进行中的后台任务或子 Agent 调度会以轻量状态卡片的形式展示，直观反映当前执行阶段。
- **模型切换与任务终止：** 在对话输入框底部即可直接查看或覆盖当前生效的模型路由；支持一键终止正在执行的会话轮次。
- **身份绑定的内置浏览器：** Local App 路由与网页链接均在身份绑定的内置浏览器页面中安全打开，在保持同源认证会话的同时，防止认证凭据意外泄露给外部第三方应用。

## 原生文件与产物查看

点击 Agent 对话界面中的文件夹或操作图标，即可浏览关联的工作区与生成产物：

- **大文件分页加载：** 文件通过专用的原生阅读器以分块分页的方式读取，即便是大型 Markdown 报告、代码 Diff 或长日志，也不会引起界面滑动卡顿。
- **即时搜索与语法高亮：** 支持文本全文高亮搜索，并对主流编程语言提供语法着色。
- **媒体与文档预览：** 生成的图片支持手势缩放，PDF 文档提供轻量的分页预览。
- **复制源码原格式：** 长按任意富文本块选择 **Select source text**，即可将未渲染的 Markdown 原始内容完整复制到剪贴板。

## 系统集成与分享收件箱

- **系统分享扩展（Share Sheet）：** 在 Safari 或系统“文件”中选中文字、网页链接或照片，打开系统分享菜单选择 Holon，挑选目标 Agent 即可直接一键发送。
- **离线暂存：** 分享时若设备处于离线状态，内容会自动沉淀到 **Settings** -> **Share inbox** 中，待重新连网后可统一核对并派发。

## 举报 AI 内容

若发现助手回复存在不准确、违规或有害内容，可以直接在应用中发起举报：

1. 长按对应的助手消息或其轮次容器。
2. 在上下文菜单中选择 **Report AI content**。
3. 选择适用的分类（如有害、内容不准确、侵犯版权等）。
4. 可选填写补充说明。
5. 点击 **Submit Report**。

客户端会将举报提交至 `POST /api/content-reports`。服务端仅会保存该条回复的有界认证快照供管理员复核，不会保存整段对话。请核对选中的文本：回复自身可能包含敏感信息。运行时接收举报不代表已完成人工审核。

## 连接管理与诊断

- **切换连接：** 在 **Settings** -> **Connections** 中查看已保存的端点，左滑即可清理不再使用的服务器配置。
- **诊断报告：** 在 **Settings** -> **Diagnostics** 中可生成脱敏的连接诊断报告，涵盖连接状态、系统版本和事件计数，便于在遇到问题时提供排查依据。

## 验证结果与文件访问

1. 核对保存的连接地址，确认目标 Agent 成功收到测试指令并返回了最新的完成摘要。
2. 从该 Agent 对话中打开 **Files**，选取一份安全的文本文件，核验文件内容与工作区归属。
3. 点击摘要中引用的产物链接，确认能够定位到正确的运行时文件（特别是 Agent 处于独立 Worktree 时）。
4. 退出应用后重新打开并刷新。在应用缓存限额内可以离线浏览对话文本；执行细节与关联文件并未承诺支持离线下载。

## 故障排查

- **Wi-Fi 下无法连接：** 检查 iOS 本地网络权限是否开启、服务器地址是否准确、主机监听端口是否开放。实体手机无法通过手机本机的 `localhost` 访问电脑。
- **配对失败：** 重新生成一张新的配对邀请二维码。兑换前确认主机地址正确，且手机所在网络能触达该主机。
- **组织登录返回后未建立会话：** 重新尝试登录并检查运行时的 OIDC 对应配置。切勿改用共享的本地 Token 绕过。
- **对话能打开但文件无法加载：** 恢复在线网络连接。确认引用的工作区或执行根目录依然存在且可读；缓存对话并不会全量离线缓存所有关联文件。
- **请求一直处于排队中：** 恢复连接后先检查发送队列，避免重复提交相同指令。
- **持续报错：** 在“设置”中生成诊断报告。分享前请核实脱敏状态，附带失败步骤及版本信息即可，切勿泄露身份凭据或配对票据。
