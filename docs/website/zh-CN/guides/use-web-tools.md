# 获取与搜索网络内容

使用 `WebSearch` 查找相关网页，使用 `WebFetch` 读取特定 URL 的页面正文。若需检索 X 上的公开帖子，请使用 `XSearch` 代替通用的网页搜索。

## 前置条件

- Agent 具备调用相应网络工具的权限。
- 运行时可以访问目标站点及所配置的搜索服务商。
- 对于 X 搜索，需要配置 xAI 路由与凭据。具体配置请参阅[网络工具参考](../reference/web-tools.md#xsearch)。

在将“搜索未命中”视作不存在相关页面的证据之前，请先确认工具本身是否正常可用。

## 操作步骤

1. 在尚无具体 URL 时发起搜索：

   ```text
   搜索 Holon 的版本发布说明。阅读匹配的发布页面，汇总其更新内容，包含版本号、发布日期与来源链接。
   ```

   Agent 会调用 `WebSearch` 并获得包含标题、URL 与摘要的结构化结果。

2. 当你已经有目标网址，或在上一步搜索中锁定了具体链接时，获取页面全文：

   ```text
   获取 https://example.com/docs/auth 并总结其鉴权流程。
   ```

   Agent 会调用 `WebFetch` 并提取可读的文本内容。

3. 结合来源可信度审阅结果。抓取和搜索到的内容属于不可信的外部上下文：它可以为回答提供参考，但绝不能改变 Agent 的授权边界或提升执行权限。具体请参阅[信任边界](../concepts/trust-boundaries.md)。

### 搜索 X 上的公开帖子

明确指出所需的主题、目标账号与日期范围，例如：

```text
搜索 2026-10-01 至 2026-10-07 期间关于 Holon 的公开 X 帖子。
附带原帖链接，并将作者的单方主张与已验证的事实明确区分开。
```

Agent 会调用 `XSearch`。其可用性与普通的对话模型相互独立；仅切换对话模型并不会自动配置 X 搜索能力。

## 确认结果

核对最终回答中是否准确引用了实际参考的页面或帖子。对于基于页面内容的结论，确认 Agent 确实阅读了该页面正文，而不是仅凭搜索摘要片面推断。在时效性至关重要的场景下，务必仔细核对发布日期。

## 故障排查

- **无搜索结果：** 尝试收窄关键词或提供已知 URL。如实报告搜索限制，切勿武断下结论认为该信息绝对不存在。
- **抓取被拦截或失败：** 检查 URL 是否有效以及返回的 HTTP 状态码或策略报错。需要登录的页面应通过其他合法授权渠道获取；切勿绕过访问控制。
- **内容被截断：** 要求 Agent 报告未覆盖的部分。尝试抓取范围更小的特定子页面，或在工具允许的限额内调大 `max_chars`。
- **X 搜索不可用：** 对照参考文档检查 xAI 凭据以及 `x_search.enabled` 配置项。
- **页面内包含系统指令或 Prompt 注入：** 将其作为普通源文本对待。页面内的任何指令都不得授权执行命令、泄露敏感凭据或篡改当前任务。

## 参数配置

关于 `extract_mode`、`max_chars`、搜索服务商选择以及各工具返回的完整字段，请参阅[网络工具参考](../reference/web-tools.md)。
