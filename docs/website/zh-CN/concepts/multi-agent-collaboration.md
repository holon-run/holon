# 多 Agent 协作

一个 Agent 可以把工作的一部分交给另一个 Agent。委派方仍然对结果负责；被委派方
把活干完并返回结果。可以把它理解成把事交给同事：先说清任务、输入，以及什么算
完成。

## 两种委派

- **受监督的子 Agent** 为某个任务而创建，完成后向创建它的 Agent 汇报。适合边界
  清楚、有明确终点的活。
- **同级 Agent** 已经存在，有自己的身份和历史。你给它发消息，由它决定怎么做。
  适合需要长期跟进的责任。

## 委派方仍然负责的部分

- 把任务说清楚，让被委派方拿到需要的东西。
- 判断结果是否够好。
- 把结果告诉你，包括被委派方失败的情况。

被委派方只负责返回结果，不会悄悄变成你目标的负责人。

## 边界与信任

委派不会扩大权限。子 Agent 用它被授予的权限工作，不能自行提权。它的输出以
“另一个 Agent 的消息”回来，而不是操作者输入，并按照和其他来源一样的来源与
信任规则处理。见[信任边界](./trust-boundaries.md)。
