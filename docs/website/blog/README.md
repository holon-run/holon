# Blog

Holon is an early-stage project. This Blog explains the problems behind the
runtime, documents what we observe in practice, and provides paths you can
reproduce in your own environment.

## What belongs here

- **Ideas** explain why long-lived, event-driven agent work needs a runtime.
- **In Practice** reports observed workflows, evidence scope, and limitations.
- **Guides** turn runtime concepts into reproducible steps.
- **Updates** will cover releases and material project changes.

Product contracts and command details remain in the documentation. Blog posts
provide context and practical interpretation; when the two differ, current
runtime documentation and release notes are authoritative.
