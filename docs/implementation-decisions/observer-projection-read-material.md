# Observer projection read material

Roster inventory and wire framing use the Host accounting scope. Each Agent's
State and posture acquisition uses that Agent's unchanged phase allowance and
the shared Host ledger. The roster retains every Agent acquisition through the
last wire owner. An explicitly enclosing acquisition remains authoritative for
the whole read; nested adapters cannot reset its failed allowance.

Posture selects open Work and active Triggers and shares Work bodies between
display groups. Completing/completed Work history cannot determine posture.
State still includes its existing bounded Work display history. Its closure
projection reads live Work execution authority without acquiring historical
Attempt, outcome or activation-wait bodies. Dispatch retains its full protocol
read and validation path. Observer reads do not grant execution authority.

Startup retains the bounded Work display window, but only the current owning
Work closure contributes mandatory Input roots. Completion source Messages and
Turns belonging only to historical display Work do not become startup inputs.
Current Work, live waits/frames, pending inputs and independently selected
history keep their existing strict qualification and closure rules.

Scheduler preparation retains the owner's display window and derives execution
Input roots from only live Work plus explicitly addressed Work, Wait, Task and
binding roots. The canonical planner still consumes its full Work queue.
Unrelated completed display records do not become mandatory execution Work
inputs. Explicitly addressed terminal execution records remain strict.

Owner preparation checks Scheduling and Input selection availability without
constructing an owning capture that would immediately be discarded. The actual
consumer still captures under the original allowance and performs complete
protocol, closure and allocation validation before making a decision. This
removes duplicate temporary allocations rather than resetting an allowance.

Direct typed State/identity decoding and child DTO cloning use the typed
allocation envelope. Byte limits, record limits, cumulative rejection, schema
and qualification checks remain unchanged. This change requires no data repair.

Direct typed selector, coverage, Work queue, Todo and current-input clones count
owned value cells, retaining the existing conservative byte envelope. Tests use
an independent decoded-value oracle and cover rejection on both resource axes.

Ordinary scheduler observations use the same live Input frontier and Brief
window as prepared scheduler reads. A broader Context publication can coexist
without being copied into post-model sleep/closure observations. Captures remain
pure and reject a missing scheduler window rather than silently preparing it.

Task reads supply Memory transactions with an unforgeable, scope/ledger-bound
proof of their existing owning guard. The original Task envelope and cumulative
Memory limits both apply before decoding; Memory retains the same guard instead
of registering and adding a second generic per-row envelope. This proof grants
no qualification or mutation authority. The source-ACK path mutates its admitted
current coverage in place and moves it into the delta; persistence reuses that
envelope and admits only positive metadata growth. Newly observed Output
selectors remain separately charged before allocation.

Unfinished-dispatch startup and physical-stop address checks treat an absent
legacy identity incarnation as one, matching the typed identity contract.
Explicit null, noninteger and nonpositive values remain invalid; current and
retired incarnation comparisons remain strict.

Dispatch-memory closure still reads and validates every execution-protocol
record. It streams Attempt/outcome pairs and retains only the Work map. The
aggregate and streaming paths share the same per-record invariant rules; all
inventory bounds and same-scope, same-transaction material checks remain. The
reserved row envelope covers the largest reciprocal pair, and rows are dropped
before advancing the cursor. Historical records never enter the memory planner.
Work queue projections retain their eight-copy envelope. The forty-copy
snapshot/planner envelope applies only to the exact State-selected Open Work
and selected Waits, plus shared metadata; completed display Work does not enter
the working-memory snapshot. The admission retains the exact State reference
used by finalization.

Original Work ACKs use the same live/current owning closure plus their exact
written Work/Wait/Frame keys. The full display delta remains available; its
unrelated historical Input references do not repopulate the execution frontier.
Explicitly written terminal records retain their strict Input dependencies.

Task status heads that depend only on an unchanged exact Task locator, with no
cleanup artifact or child relation, move from the admitted prior coverage into
the final coverage. Only a destination map node is new. Heads with external
cleanup/delegation dependencies are still reobserved using the original rules.

The Scheduling loader moves its owned keyed map into the resident domain.
Canonical ordered observations use an adjacent uniqueness check; legacy
unsorted observations retain the borrowed-set validation path. The receipt
moves the keyed map behind one shared header rather than constructing another
body-slot vector. Scope, locator revision, body/index
completeness, wake-parent relations and both admission axes remain validated.
