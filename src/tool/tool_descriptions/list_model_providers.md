List configured/discovered model providers. `media` summarizes image input/output support across observed routes (supported means at least one route, not every model); unknown/incomplete is not unsupported. Optional operation=view_image|generate_image filters to providers with currently callable models for that operation. By default unavailable providers are omitted; include_unavailable=true is diagnostic only and also shows blocked operation candidates with reasons. Use ListProviderModels to inspect exact endpoint/model contracts; listing never grants authority.
