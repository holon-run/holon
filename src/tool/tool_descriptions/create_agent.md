Create an independent, persistent, self-owned agent identity. `agent_id` is required and must be stable. `name`, `template`, `initial_message`, and `model` are optional. The initial message is bootstrap input only: it is delivered only when a new identity is created, does not create a result-bearing task, and is never sent by a duplicate create. Caller provenance, authority, lineage, supervision, durability, and lifecycle attachment are bound by the runtime and are not request fields.
