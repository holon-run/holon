Record an explicit wait condition and yield the current turn. Every call must choose delivery=final or delivery=silent. Use final when the turn must publish a non-empty operator-facing assistant final before waiting; provide the final text immediately when no further verification is needed. If the runtime opens a pending-report continuation, follow the restricted continuation contract below. Use silent when no operator-facing brief is needed; the runtime settles the wait without another model round. The selected delivery, wait registration, tool evidence, turn terminal, and queue terminal are committed together, so a stale task, execution binding, WorkItem revision, wake, or interjection cannot publish an obsolete waiting report. Use wake=task_result with resource=<task_id> when waiting for a background task. For every wake kind the waiter is the current execution-bound WorkItem when one exists; a conflicting explicit work_item_id is ignored and disclosed in the receipt instead of failing. Without an execution binding, optional work_item_id explicitly selects an open WorkItem owned by this agent, then the turn-bound WorkItem, then current focus; if none exists it records an agent-lifecycle wait. The task may belong to any WorkItem of this agent (tasks of other agents are rejected); waiting never migrates the task or changes its owner. Optional recheck_after_ms records a fallback recheck deadline.

Before calling `WaitFor(delivery=final)`, finish any required queries, verification, and material collection. The runtime then enters a pending-report continuation and requires non-empty operator-facing final text. That continuation may use read-only fact-checking tools, but do not call `WaitFor`, `CompleteWorkItem`, or another lifecycle-control tool recursively. Use any tool results first, then provide the final report as text. For other wake kinds, use `wake=external` with optional `resource=<external object such as a URL or github:owner/repo#id>` when waiting for outside state, or `wake=operator_input` when waiting for the operator.
