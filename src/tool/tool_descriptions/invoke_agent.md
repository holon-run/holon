Invoke an agent asynchronously and return its `agent_id`, whether this request created it, and a result-bearing `TaskHandle`. `target` is a strict discriminated union: use `kind=existing_agent` with only `agent_id`, or `kind=new_subagent` with optional `template`, `workspace_mode`, and `model`. `initial_message` is required. Existing-agent invocation never reconfigures or reparents the target; new-subagent invocation creates a private supervised child. Caller provenance and authority are bound by the current runtime context and cannot be supplied in the request.
