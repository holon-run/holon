Use WaitFor when progress is intentionally paused until a specific wake condition: `wake=task_result` with `resource` set to the task id, `wake=timer` with `resource` set to an existing timer id, `wake=system` for the next non-work-queue system wake, `wake=external` with `resource` set to a stable outside object such as a URL or `github:owner/repo#123`, or `wake=operator_input` when only the operator can unblock the work. Always provide a concrete `reason`. Optional `recheck_after_ms` records a timed fallback recheck.

Every call must explicitly choose `delivery=final` or `delivery=silent`. Use `final` when the current turn needs a non-empty operator-facing final report before waiting; after the tool request, reply with final text only and do not call another tool. Use `silent` when no user-facing brief is needed; it settles without another model round. The runtime commits the selected delivery, wait, successful tool evidence, turn terminal, and queue terminal atomically.

Wait ownership resolves from an explicit owned open `work_item_id`, then the execution-bound WorkItem, then the turn-bound WorkItem, then current focus; if none exists, the wait belongs to the agent lifecycle. Focus is only a fallback and does not change an existing execution or task owner. A task-result wait must have the same agent and WorkItem owner as the task, so an explicit `work_item_id`, a later CreateWorkItem, or PickWorkItem cannot migrate or bypass the task's captured owner. A task created without any WorkItem owner can be awaited at agent-lifecycle scope without first creating or picking a WorkItem.

WaitFor may consume an already available task result instead of registering a new wait; use the returned disposition and `terminal_transition` rather than assuming every successful call yields the turn. If task state, execution binding, WorkItem revision, or wake state changes before settlement, the runtime rejects the stale prepared wait rather than publishing an obsolete final report. Do not use UpdateWorkItem blocked fields for new waits.
